# Project Documentation for IBC Alumni Network Form

## Project Overview
The IBC Alumni Network Form is designed to facilitate communication and connection among alumni of the Illinois Business Consulting (IBC). This form allows alumni to share their information, provide feedback, and stay updated on events and opportunities within the alumni community.

## Features
- User-friendly interface for data entry
- Sections for personal information, professional background, and interests
- Responsive design to support various devices
- Data storage for further analysis and tracking alumni engagement

## Form Sections
1. **Personal Information**: Includes fields for name, email, phone number, and graduation year.
2. **Professional Background**: Allows alumni to share their current job title, employer, and industry.
3. **Interests**: Provides options for alumni to select interests or areas they would like to contribute to within the community.
4. **Feedback**: A section where users can give feedback about their experiences with IBC programs and suggest improvements.

## Setup Instructions
1. **Clone the Repository**: Use `git clone` to get a local copy of the repository.
2. **Install Dependencies**: Run `npm install` in the project directory to install necessary packages.
3. **Run the Application**: Use `npm start` to launch the application locally.
4. **Configure the Database**: Ensure that the database is set up correctly according to the instructions provided in the `DB_SETUP.md` file.

## How to Use the Form
1. Fill in the required fields in the Personal Information section.
2. Complete the Professional Background and Interests sections.
3. Provide feedback if applicable.
4. Submit the form to save your information.
5. Review any confirmation message that appears post-submission.

Feel free to reach out to the project maintainers if you have any questions or need assistance.
